# Responsive Web Design Projects

This repository contains my completed projects for the **freeCodeCamp Responsive Web Design Certification**. Each project demonstrates core web development fundamentals using modern HTML5 and CSS3, with a focus on semantic structure, CSS Flexbox, CSS Grid, media queries, and responsive layouts across all device screens.

---

## 📂 Projects Overview

| Project | Description | Key Features & Concepts |
| :--- | :--- | :--- |
| **[Tribute Page](./tribute-page)** | A responsive tribute page highlighting key events and information about a subject. | Semantic HTML structural elements, centered layout containers, responsive image scaling, styled typography. |
| **[Survey Form](./survey-form)** | A user feedback form designed to collect structured inputs. | HTML5 form validation, native input types (radio buttons, checkboxes, dropdowns, text areas), mobile-friendly form controls. |
| **[Product Landing Page](./product-landing-page)** | A modern marketing page showcasing a product or service. | Fixed header navigation, embedded HTML5 video, CSS Flexbox/Grid page structure, media queries for responsive layouts. |
| **[Technical Documentation](./technical-documentation)** | A technical reference page designed to read like developer documentation. | Fixed sidebar navigation, main content layout, custom code block styling, responsive drawer/stack behavior. |
| **[Personal Portfolio](./meme-personal-portfolio)** | A portfolio page created to showcase web development projects and contact information. | Full-width header section, fixed navbar with internal jump links, project card grid, responsive media queries. |

---

## 🛠️ Technologies Used

* **HTML5:** Semantic element tags, form structure, media embedding, and accessibility markup.
* **CSS3:** Custom properties (variables), Flexbox, CSS Grid layout, media queries (`@media`), and responsive styling.
