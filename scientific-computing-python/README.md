# Scientific Computing with Python Projects

This repository contains my completed projects for the **freeCodeCamp Scientific Computing with Python Certification**. Each project demonstrates core Python concepts, including string manipulation, algorithmic logic, data structures, and Object-Oriented Programming (OOP).

---

## 📂 Projects Overview

| Project | Description | Key Concepts & Techniques |
| :--- | :--- | :--- |
| **[Arithmetic Arranger](./arithmetic-arranger)** | Formats arithmetic problems vertically and side-by-side to mimic primary school math layouts. | String formatting, input validation, list parsing, conditional logic. |
| **[Time Calculator](./time-calculator)** | Adds a duration string to a start time in 12-hour AM/PM format and returns the updated time and day. | Time arithmetic, modular math, string parsing, conditional branching. |
| **[Budget App](./budget-app)** | An object-oriented budget manager with ledger tracking and spending visualization. | Object-Oriented Programming (classes & methods), data structures, text-based chart generation. |
| **[Polygon Area Calculator](./polygon-area-calculator)** | Geometry calculator utilizing class inheritance to compute shape dimensions, areas, and object fitting. | OOP Inheritance (`Rectangle` & `Square`), class methods, geometry calculations. |
| **[Probability Calculator](./probability-calculator)** | A Monte Carlo simulation tool that estimates the probability of drawing specific ball combinations from a hat. | Monte Carlo simulation, randomness (`random` module), custom class logic, probability theory. |

---

## 🛠️ Technologies & Concepts

* **Language:** Python 3
* **Paradigm:** Object-Oriented Programming (Classes, Inheritance, Encapsulation)
* **Algorithms & Logic:** Monte Carlo Simulations, String Manipulation, Modular Arithmetic, Data Parsing
